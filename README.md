# Kabamba Analytics Hub (`kabamba.org`)

Bilingual (`EN` / `FR`) capital valuation and wealth-planning gateway routing users into specialized Streamlit analytical engines.

## 3-Door Capital Mandate Routing

| Door | Mandate | Destination Engine | Pre-Calibrated Focus |
| :--- | :--- | :--- | :--- |
| **Door 01 · Personal Wealth** | Individual Investors & Families | `kabamba-fire-calculator.streamlit.app` | Coast FIRE milestones, multi-currency compounding runways, safe withdrawal rates, and liquidity exit handoffs |
| **Door 02 · Real Assets & Mining** | Junior Miners & Project Developers | `kabamba-appraisal-tool.streamlit.app` | Multi-year CapEx, exploration DCF, commodity sensitivity, reclamation liabilities, NPV, IRR & MIRR |
| **Door 03 · Institutional Credit** | Banks, Funds & Credit Committees | `kabamba-appraisal-tool.streamlit.app` | Senior debt service coverage (`DSCR`), leveraged vs. unleveraged returns, lease-vs-buy, and board PDF memos |

## Cross-App Liquidity Handoff

Completed capital-project exits in the **Investment Appraisal Engine** generate deep-linked URL parameters (`portfolio`, `age`, `target_age`, `spend`, `currency`, `lang`) that pre-populate the **FIRE Runway Tracker** automatically.
